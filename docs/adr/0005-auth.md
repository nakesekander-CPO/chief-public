# ADR 0005: Dispatch-owned ChatGPT sign-in

**Status:** Accepted · 3 September 2026

Use Sites dispatch-owned SIWC and forwarded authenticated-user headers. Server code owns authorization and D1 keys records by stable per-Site user ID. Local demo fallback is isolated to the Sites development environment. Authentication does not imply workspace membership; all workspace reads and writes remain server-scoped.
