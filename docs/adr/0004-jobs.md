# ADR 0004: Durable explicit job state machine

**Status:** Accepted · 3 September 2026

Represent work as queued, running, succeeded, failed, canceled, awaiting approval, or dead letter. Transitions, leases, retry budgets, exponential backoff, and idempotency are normal code in `lib/jobs.ts`. The private demo does not register a hosted scheduler; production may bind the same state machine to Cloudflare Queues/Cron or another durable executor.
